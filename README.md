# n8n-render-deploy
# n8n Self-Hosted on Render (Free Tier)

This repository contains a minimal setup to host your own instance of **n8n** on [Render.com](https://render.com) using **Docker**.

## 🚀 How to Deploy

1. **Fork or Clone** this repository.
2. Push it to your **own GitHub repo**.
3. Go to [Render.com](https://render.com), create a free account.
4. Click "New" → "Web Service".
5. Select your repo, choose **Docker** as the environment.
6. Click "Deploy".

## 🔐 Credentials

- Username: `admin`
- Password: `securepassword`

You can change these in the `Dockerfile` for security.
